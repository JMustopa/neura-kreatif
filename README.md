# NEURA KREATIF — Website (HTML/CSS, v1)
Built from: Figma NEURA WEBSITE (identity), Design System v1.1 (tokens.css), Company Profile deck 2026 (content), STRUCTURE.md (sitemap).

## Open it
Open `index.html` in a browser — all links/assets are relative, no build step, no server needed.
Geist is self-hosted (assets/fonts/, variable 100-900, OFL license included). An internet connection is needed only for Archivo from Google Fonts.

## Pages
- `index.html` — Home
- `work/index.html` — Work index (with filters) · 4 case pages in `work/`
- `services/index.html` — Services (3 capabilities + How we work + FAQ)
- `about/index.html` — About + team + clients
- `contact/index.html` — Contact + project brief form (opens email to admin@neurakreatif.com)

## Edit / rebuild
Page HTML is generated by `../build.py` (shared nav/footer/components live there).
Edit content in build.py, then run: `python3 ../build.py`
Styles: `assets/css/tokens.css` (design tokens — do not fork values) + `assets/css/styles.css`.
